# Projet Technique - Sprint 0

## Description
Bienvenue dans le dépôt du **Projet Technique**.
Cette branche (`Sprint-0`) correspond à la phase initiale de cadrage, de mise en place de l'environnement et de structuration du projet.

## Objectifs du Sprint 0
- Cadrage du projet et définition des besoins.
- Initialisation du dépôt Git et organisation des branches (`main`, `Sprint-0`, `S1`, `S2`, `S3`).
- Préparation de l'environnement de développement et de la structure de base.

- **Sprint 0** : Cadrage, mise en place initiale et documentation.
